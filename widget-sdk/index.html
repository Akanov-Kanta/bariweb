BariWeb Инклюзия

Этот демонстрационный сайт предназначен для тестирования всех функций BariWeb Widget SDK. Используйте панель управления слева (синяя кнопка), чтобы адаптировать страницу под свои нужды.

Тестирование Чтения

Попробуйте включить Дислексический шрифт или изменить Межстрочные интервалы. Текст должен стать более разреженным и читаемым.

Тестирование Зрения

Включите ЧБ Режим или режим Высокой Контрастности. Обратите внимание, что цвета изменятся только для виджета, если не прокинуть переменные на родителя.
