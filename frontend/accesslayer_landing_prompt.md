# AccessLayer — Промпт для AI-агента (Cursor / v0 / Lovable)

## Контекст продукта

AccessLayer — B2B SaaS виджет доступности для казахстанского и СНГ рынка. Продаётся корпорациям (банки, e-commerce, госсервисы) как страховка от штрафов по Цифровому кодексу РК, вступающему в силу 11 июля 2026 года. Интеграция: одна строка кода. Продукт делает сайт доступным для людей с инвалидностью автоматически — голосовой ИИ-агент, когнитивный упрощитель, ARIA-атрибуты.

Тарифы: Starter $299/мес, Business $1 200/мес, Enterprise/Gov $3 500/мес.

Стек лендинга: Next.js 14, TypeScript, Tailwind CSS, shadcn/ui. Текущий лендинг уже существует — нужно **добавить** следующие секции и интерактив. Все тексты на русском.

Дизайн-система: тёмный фон (#0a0a0f, #0d0d14), акцент синий (#3b82f6), вторичный акцент cyan (#06b6d4), текст белый/серый. Шрифт: Geist или Syne для заголовков, Inter для body. Стиль: premium dark SaaS, как Vercel + Linear.

## СЕКЦИЯ 4 — FAQ

**Расположение:** после тарифов, перед CTA

**Заголовок:** `Частые вопросы`

**Аккордеон** — 6 вопросов, открываются по клику, плавная анимация высоты (max-height transition):

1. **Виджет сломает мой сайт?**
   Нет. AccessLayer работает как изолированный слой поверх DOM. Он не изменяет ваш код, только добавляет accessibility-атрибуты и слой взаимодействия. Откат за 30 секунд — удалите одну строку.

2. **Кто несёт юридическую ответственность за compliance?**
   AccessLayer выдаёт Сертификат соответствия Цифровому кодексу РК (тариф Enterprise/Gov). Этот документ принимается регулятором как подтверждение выполнения требований.

3. **Как быстро подключить?**
   Добавьте одну строку кода в `<head>` вашего сайта. Виджет активируется автоматически и начинает работу без дополнительной конфигурации. Среднее время интеграции: 12 минут.

4. **Что если Цифровой кодекс изменится?**
   Мы мониторим изменения законодательства и обновляем виджет автоматически. Ваш сайт всегда актуален — без участия вашей команды.

5. **Подходит ли для уже существующего сайта?**
   Да. AccessLayer работает с любым сайтом независимо от технологии — WordPress, 1С-Битрикс, самописные решения, SPA на React/Vue. Без редизайна.

6. **Есть ли пробный период?**
   Да — бесплатный compliance-аудит вашего сайта с детальным PDF-отчётом. Без звонков менеджера, результат за 24 часа.

**Стиль аккордеона:** каждый вопрос — строка с правым шевроном (rotates 180° при открытии). Открытый ответ — серый текст 14px, line-height 1.7. Разделители между вопросами — тонкие линии.

## СЕКЦИЯ 5 — Countdown до дедлайна

**Расположение:** sticky banner вверху страницы (под навбаром) ИЛИ внутри секции "Проблема"

**Компонент:** горизонтальная полоса. Левый пульсирующий красный dot + текст "До вступления в силу Цифрового кодекса РК:" + **цифровой таймер** (дни : часы : минуты : секунды, обновляется каждую секунду) + правее кнопка "Начать сейчас →"

**Целевая дата:** 11 июля 2026, 00:00 по Алматы (UTC+5)

**JavaScript:**
```js
const deadline = new Date('2026-07-11T00:00:00+05:00');
function updateTimer() {
  const diff = deadline - new Date();
  const days = Math.floor(diff / 86400000);
  const hours = Math.floor((diff % 86400000) / 3600000);
  const mins = Math.floor((diff % 3600000) / 60000);
  const secs = Math.floor((diff % 60000) / 1000);
  // обновить DOM
}
setInterval(updateTimer, 1000);
```

**Стиль:** фон `rgba(239,68,68,0.08)`, border-bottom `0.5px solid rgba(239,68,68,0.2)`. Цифры таймера — моноширинный шрифт (font-variant-numeric: tabular-nums), 18px, белые. Подписи под цифрами (дни/часы/мин/сек) — серые, 10px.

## ИНТЕРАКТИВ 2 — 3D hero (замена статичного куба)

**Вместо куба** — анимированная **сеть нейронов/нодов** (particle network), символизирующая ИИ-агента.

**Технология:** Three.js (подключить через CDN) или pure CSS/Canvas если Three.js недоступен.

**Описание эффекта:**
- 60–80 частиц (nodes) разных размеров (2–6px), белые с разной прозрачностью
- Частицы медленно дрейфуют в 3D-пространстве
- Между близкими частицами (<150px) рисуются линии с opacity пропорциональной расстоянию
- При движении мыши: камера или поле частиц слегка поворачивается (parallax эффект, ±15°)
- Несколько частиц "пульсируют" — увеличиваются и уменьшаются (scale 1→1.8→1), синий цвет `#3b82f6`
- Периодически (каждые 3–4 сек) одна связь "активируется" — линия вспыхивает синим и гаснет

**Размер:** занимает правую половину hero-секции (правые 45% экрана), высота = высота hero

**Canvas:** `position: absolute`, `right: 0`, `top: 0`, `width: 50%`, `height: 100%`, `z-index: 1`

**Текст hero** поверх, z-index: 2, левые 55%

**Цвета частиц:** белые `rgba(255,255,255,0.6)`, линии `rgba(255,255,255,0.08)`, активные ноды `#3b82f6`, активные линии `rgba(59,130,246,0.6)`

## ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

- Все секции адаптивны (mobile-first, breakpoints: 640px, 1024px)
- На мобильном: 3D-эффект отключается (заменяется статичным градиентом), grid становится 1 колонка
- Анимации: используй `prefers-reduced-motion` media query — при включённом режиме все анимации отключаются (важно для accessibility, это ваш продукт!)
- Intersection Observer для lazy-анимаций появления секций
- Таймер обратного отсчёта работает без серверного времени (клиентский JS)
- Live Demo не требует бэкенда — всё фронтенд симуляция
- Калькулятор ROI — чистый JS, без fetch

## ВАЖНЫЙ КОНТЕКСТ

Продукт сам является инструментом доступности — лендинг обязан соответствовать WCAG 2.1 AA:
- Все интерактивные элементы доступны с клавиатуры (Tab + Enter/Space)
- Кнопки имеют aria-label
- Цветовой контраст текста ≥ 4.5:1
- Анимации уважают prefers-reduced-motion

Это не просто хорошая практика — это демонстрация продукта на самом лендинге.
